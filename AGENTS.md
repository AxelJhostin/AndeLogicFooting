# Instrucciones para colaboradores e IA

1. Lee todos los archivos de `docs/` antes de proponer o modificar código.
2. No implementes ecuaciones desde memoria. Registra fuente, edición, cláusula y supuesto antes de programar cada verificación.
3. Mantén el motor de cálculo independiente de React, Vite, PDF, almacenamiento y componentes visuales.
4. Escribe o actualiza las pruebas antes de modificar una fórmula.
5. No presentes una capacidad como compatible con NEC o ACI si el perfil no tiene matriz de pruebas y referencia autorizada.
6. No agregues IA, cuentas, backend o sincronización sin una necesidad documentada.
7. Conserva las exclusiones del alcance. Un caso fuera de alcance debe fallar claramente, no aproximarse en silencio.
8. No copies contenido protegido de normas de pago al repositorio. Guarda identificadores de referencia y resultados derivados autorizados.
